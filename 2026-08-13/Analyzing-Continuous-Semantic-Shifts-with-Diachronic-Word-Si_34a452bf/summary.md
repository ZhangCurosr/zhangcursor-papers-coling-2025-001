# 论文速读：Analyzing-Continuous-Semantic-Shifts-with-Diachronic-Word-Similarity-Matrices

## 一句话总结
本文提出一种基于**历时词相似矩阵（Diachronic Word Similarity Matrix）**的轻量级无监督框架，通过计算同一词在任意跨时段词向量间的余弦相似度，完整刻画词义连续漂移轨迹，并结合PPMI差值与矩阵聚类实现可解释的语义演变分析与词汇分组。

## 研究问题与动机
- **核心问题**：如何细致分析词义在多个时间段内发生的连续漂移过程，而非仅定位相邻时段的突变点。
- **相邻时段方法的局限**：传统变化点检测（如Kulkarni et al., 2015）只能标记相邻时段距离变化，无法区分词义是“回归原义”还是“跃迁至新义”。
- **BERT类方法的高昂成本**：基于上下文嵌入的词义比例分析（如Hu et al., 2019; Giulianelli et al., 2020）计算开销极大，严重限制目标词汇规模。
- **先验类型假设的束缚**：多数现有研究预设了特定的漂移Schema，缺乏对未知/混合漂移模式的通用分析能力。

## 核心贡献（创新点）
1. **历时词相似矩阵框架**：将多时段词向量转化为$T \times T$余弦相似度矩阵，直接可视化任意时间段内的连续漂移轨迹；与相邻时段差值方法本质不同，可捕捉漂移后的回归或二次跃迁。
2. **矩阵聚类的无监督词汇分组**：提取相似矩阵上三角特征并聚类，自动归纳出具有相似漂移动力学特征的词群（如受同一社会事件驱动的词汇）；区别于传统基于单点距离的聚类，本文捕捉的是完整时序模式。
3. **PPMI差值驱动的可解释细读**：在相似矩阵中定位高/低相似区块后，计算$\Delta M^{(t_2 \to t_1)}$提取Top-$k$共现词，将抽象的向量漂移映射回可理解的语境变化；前人工作多停留在距离度量，缺乏此类闭环解释路径。
4. **伪数据分类的系统性验证**：在Shoemark等7类伪偏移模式上对比多种特征/聚类组合，定量证明全时段上三角特征+标准化显著提升分类准确率，为框架有效性提供可复现的基准。

## 方法详解
- **输入准备（PPMI-SVD joint）**：对每时段$t$构建PPMI共现矩阵$M_{wc}^{(t)} = \max(\log\frac{p(w,c)}{p(w)p(c)}, 0)$，对所有时段联合进行SVD压缩$M^{(t)} = U\Sigma V^T$，取$W = U\Sigma^{1/2}$获得维度对齐的$D$维权重向量，替代SGNS以保证跨时段可比性。
- **相似矩阵构建**：对目标词$w$，计算$S_{ij}(w) = \cos(e_i(w), e_j(w))$，得到$S(w) \in \mathbb{R}^{T \times T}$。矩阵对角线为1，高相似块表示词义稳定期，低相似块或尖峰表示漂移发生期。
- **特征提取与聚类**：截取上三角元素（剔除对称重复），进行标准化后拼接为长向量；采用层次聚类（Hierarchical Clustering）对所有词的矩阵进行无监督分组，COHA聚类阈值设为8，COCA设为30。
- **漂移解释流水线**：
  1. 通过可视化或轮廓系数定位相似矩阵中的结构性突变（区块分裂、尖峰）；
  2. 选取对应时段$t_1, t_2$计算PPMI差值$\Delta M^{(t_2 \to t_1)} = M_{w*}^{(t_1)} - M_{w*}^{(t_2)}$；
  3. 提取$\mathcal{N}_k^{(t_2 \to t_1)} = \text{argsort}(\Delta M)_{[:k]}$，解读漂移前后的具体共现词更替。

## 实验与结果
- **数据集**：英文历史语料库**COHA**（1830–2010，10年/期，19时段，3,231目标词）；英文当代语料库**COCA**（1990–2019，1年/期，30时段，2,805目标词）；日语《每日新闻》（2003–2020，18时段）。
- **评估设置**：对比相似度度量（Cosine/Euclidean）、特征提取（Adjacent/Period 0/Upper Tri）、聚类算法（Agglo/K-means++）、标准化（±stand）。
- **主要结果**：
  - **伪数据分类**：最佳配置（Cosine + Upper Tri + Agglo + standardization）准确率达**72.1%**，较仅用相邻时段（70.7%）与未标准化（55.7%）均有提升；C2、C3、D1、D4模式识别较好，C1、D2、D3因相似度变化幅度小或随机性强较难检测。
  - **真实数据可视化**：`record`在1930年前后相似矩阵分裂为两个高相似块，对应“记录行为”与“声音介质”两义并存；`president`在1998（Jackson纪录片）、2012（大选）、2017（Trump政府）出现明显尖峰，区块划分与社会事件高度吻合。
  - **聚类发现**：`record`与`government`/`wrong`聚为一簇，`president`与`lie`/`independent`聚为一簇；日语`復興`成功识别2011年震灾引发的语境突变，`流行`与`感染`/`ウイルス`等同簇反映COVID-19语境漂移。
- **最强结果与提升**：全时段上三角特征+标准化组合在伪数据分类上达到72.1%，相比相邻时段基线提升1.4个百分点，且在不同相似度度量下均保持最优趋势。

## 相关工作脉络
- **变化点检测（Kulkarni et al., 2015; Yao et al., 2018）**：仅计算相邻时段嵌入距离定位漂移发生点；本文扩展至任意时段相似度矩阵，可区分“回归”与“跃迁”等不同漂移形态。
- **BERT词义比例建模（Hu et al., 2019; Inoue et al., 2022）**：依赖计算昂贵的上下文模型，词汇规模受限；本文采用轻量级PPMI-SVD，支持数千量级词汇的大规模无监督聚类。
- **漂移Schema分类（Shoemark et al., 2019; Cassotti et al., 2024）**：预设监督标签进行类型划分；本文完全不依赖先验Schema，通过矩阵模式自动涌现漂移结构。
- **时序Gram矩阵方法（Zhang et al., 2016; Qiu et al., 2023）**：将人体/声音时序数据转为相似度矩阵用于分类；本文首次将该思想系统引入NLP词义漂移，并验证上三角全时段信息的不可替代性。
- **模型权重时间向量（Nylund et al., 2024）**：追踪微调模型权重变化；本文直接操作各时段词向量，避免重复微调开销，更适合跨语种/跨域快速部署。

## 局限性与未来方向
- **领域一致性假设**：跨时段语料若领域跨度大，领域差异会混入相似矩阵干扰漂移分析；需开发抗领域偏移的鲁棒方法。
- **嵌入方法单一**：仅验证PPMI-SVD，未覆盖动态上下文嵌入；未来可探索高效生成方案以支持低频词与细粒度分析。
- **伪Schema覆盖有限**：7类模式无法涵盖真实数据中的复杂多次漂移，需扩展Schema定义或设计多时段连续漂移分类任务。
- **时间粒度适应性**：10年/年粒度适合宏观漂移，未来需验证月粒度（如NOW语料库）下对细微语义波动的敏感度。
- **相似度变化≠语义漂移**：部分词汇的矩阵波动仅反映语用频率变化而非真正词义迁移，需建立更严格的漂移判定阈值与语言学验证协议。

## 研究启发与可借鉴点
1. **相似矩阵作为时序词向量的统一表征**：将高维时序嵌入压缩为单一矩阵，极大简化漂移模式的可视化、聚类与跨词比较，可无缝迁移至任何语种的历史文本分析 pipeline。
2. **全时段上三角特征优于相邻差分**：伪数据实验明确证明保留远距离时段相似度对识别复杂模式（如义项交替、周期性波动）至关重要，启发后续工作应优先尝试完整矩阵特征而非一阶差分。
3. **“矩阵定位 + PPMI反推”的可解释流水线**：先通过区块/尖峰粗定位漂移时段，再用共现词差异精确定义语义内容，形成闭环解释路径，可直接复用于数字人文、社交媒体监控或法律/医学术语演变追踪。
4. **无监督聚类作为候选词筛选器**：利用聚类结果自动圈定“疑似受外部事件驱动”的词群，可为语言学研究者提供高效的高价值词汇优先级列表，大幅降低人工筛查成本。

## 关键术语表
- **Diachronic Word Similarity Matrix（历时词相似矩阵）**：记录同一词在多个时间段词向量之间成对余弦相似度构成的对称矩阵，用于直观刻画词义连续演变轨迹。
- **PPMI-SVD joint**：对多时段共现PPMI矩阵联合进行奇异值分解，以极低计算成本获取维度严格对齐的轻量级词向量。
- **Shift Schema（偏移模式）**：预设的语义漂移典型类型（如新义获取C1、义项跃迁C2、周期尖峰D3、纯噪声D4等），本文用于伪数据生成与分类验证。
- **Change Point Detection（变化点检测）**：定位语义发生显著突变的特定时间点的传统方法，本文指出其难以区分词义“回归”与“跃迁”。
- **Gram Matrix（格拉姆矩阵）**：向量内积构成的相似度矩阵，本文将其作为时序词嵌入的特征化表示进行聚类分析。
- **Sense Reversion / Transition（语义回归/跃迁）**：词义漂移后恢复至初始状态（Reversion）或持续转向全新义项（Transition）的两种典型连续漂移形态。

## 可复现要素
- **数据集**：COHA（经CCOHA清洗）、COCA、Mainichi Shimbun均为公开语料库；附录提供了详细分词、子采样（COHA 1e-4，COCA 1e-5）与词频过滤（≥100次）设置。
- **代码/权重**：论文未提供开源代码与预训练权重，依赖开源PPMI-SVD joint实现（Aida et al., 2021）。
- **关键超参**：词向量维度100；COHA层次聚类阈值8，COCA阈值30；伪数据每Schema 20个假词共140个；线性总和指派算法（Hungarian）评估聚类标签。
