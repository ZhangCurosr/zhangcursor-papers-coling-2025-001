# 论文速读：Gradient-Inversion-Attack-in-Federated-Learning-Exposing-Text-Data-through-Discrete-Optimization

## 一句话总结
论文提出了 FET（Fully Expose Text）方法，首次在离散文本空间而非连续嵌入空间进行优化，能够从联邦学习的梯度中精确重建私有文本数据，在 CoLA 和 SST-2 数据集上精确匹配率超过 50%，显著优于已有方法。

## 研究问题与动机
- 联邦学习（FL）虽将数据保留在本地，但梯度交换仍可能泄露敏感文本信息（如手机号、地址等）。
- 现有文本重建方法（TAG、LAMP 等）主要优化连续嵌入向量，难以实现精确重建；即使嵌入向量准确，也无法可靠解码回原文。
- 文本空间具有离散性、词汇表巨大（如 BERT 为 30522）及序列长度不确定的特点，使得直接优化极具挑战。
- 研究者希望验证"仅使用更小模型参数是否足以保护文本隐私"这一假设，发现小模型同样脆弱。

## 核心贡献（创新点）
1. **首次直接在文本空间进行离散优化**：设计了结合全局搜索（遗传算法）与局部搜索（词元操作）的两阶段优化算法，与 TAG/LAMP 在嵌入空间优化的本质区别在于直接处理离散 token 序列。
2. **仅使用全连接层梯度作为损失函数**：发现全连接层梯度已足够指导优化，相比匹配所有层梯度大幅降低计算成本。
3. **显著提升精确匹配率**：在 CoLA 和 SST-2 上精确匹配率超 50%，较 TAG/LAMP 平均提升 39%（TinyBERT）、20%（BERT_base）、15%（BERT_large），证明"小模型更安全"的观点不成立。

## 方法详解
1. **梯度信息推断**：从嵌入层梯度中推断文本总 token 数 n（通过位置嵌入层非零行数）和唯一 token 集合 W（通过嵌入层非零行对应 token）。
2. **探索阶段（Exploration）**：将候选文本编码为整数列表染色体，采用自定义遗传算法（选择、交叉、变异、精英保留）在全局解空间中搜索近似最优解。
3. **微调阶段（Fine-tuning）**：以探索阶段结果为基础，通过词元级操作（swap、shift、replace）局部精炼解，确保避免重复访问。
4. **损失函数**：仅使用 L2 范数计算目标梯度与重建梯度在全连接层的距离：
   $$\arg \min_{\pmb{x} \in V^n} \left\| \frac{\partial \mathcal{L}(f_\theta(\pmb{x}), y^c)}{\partial \theta_{fc}} - g^c_{fc} \right\|_2$$
   其中 $g^c_{fc}$ 为目标全连接层梯度。

## 实验与结果
- **数据集**：CoLA（序列长度 5–9）、SST-2（3–13）、Rotten Tomatoes（14–27）。
- **模型**：TinyBERT₆（67M）、BERT_base（109.5M）、BERT_large（340M），以及 TextCNN、LSTM、ALBERT。
- **主要结果**：在 TinyBERT₆ + CoLA 上，FET 精确匹配率达 90%，远超 LAMP 的 26% 和 TAG 的 0%；在 SST-2 上精确匹配率达 62%，较 LAMP 提升 30 个百分点。
- **跨架构验证**：在 TextCNN、LSTM、ALBERT 上均有效，LSTM 效果最佳（CoLA 精确匹配率 99%）。
- **批量数据**：batch size=1 时精确匹配率 90%，batch size=2 时降至 7%，batch size=4 时为 0%，但 ROUGE 分数仍有一定提升。
- **消融实验**：探索+微调两阶段组合优于单独使用任一阶段；仅匹配全连接层（90% 精确匹配）比全层匹配（96%）效率提升约 2.7 倍（43.27s vs 115.25s）。

## 相关工作脉络
1. **DLG (Zhu et al., 2019)**：首次提出梯度反转攻击，优化嵌入向量重建图像/文本；FET 与之区别在于直接优化离散文本空间。
2. **TAG (Deng et al., 2021)**：结合 L1 和 L2 范数衡量梯度距离，用于 Transformer 文本重建；但精确匹配率极低（<8%）。
3. **LAMP (Balunovic et al., 2022)**：引入预训练语言模型作为先验，交替进行连续和离散优化；FET 更专注于精确重建而非语义自然性。
4. **FILM (Gupta et al., 2022)**：从梯度中识别 token 并用 beam search 生成句子；未优先考虑精确重建。
5. **InvGrad (Geiping et al., 2020) / GradInversion (Yin et al., 2021)**：针对图像数据的高精度重建方法；FET 将类似思路适配到文本离散空间。

## 局限性与未来方向
- 批量大小增加时搜索空间指数级膨胀，收敛困难（论文自述局限）。
- 对于包含大量重复 token 的文本，微调阶段可能需要更多迭代或更强的约束。
- 未讨论差分隐私、梯度裁剪等防御机制对攻击效果的影响。
- 未来可探索：引入更强语言模型先验、针对大批量场景的加速策略、与防御方法的对抗评估。

## 研究启发与可借鉴点
1. **离散优化框架可迁移**：两阶段设计（全局遗传探索+局部操作微调）可推广到其他离散结构恢复任务（如代码、结构化数据）。
2. **单层梯度有效性验证**：证明全连接层梯度已足够指导优化，为后续研究减少计算开销提供了依据。
3. **实验设计严谨**：涵盖多模型架构（CNN/RNN/Transformer）、多批量大小、消融实验，值得借鉴。
4. **可结合的方向**：将此攻击与差分隐私防御结合，量化隐私预算与攻击成功率的关系；或研究针对文本特性的自适应防御策略。

## 关键术语表
- **Gradient Inversion Attack**：通过优化 dummy 数据使重建梯度逼近目标梯度，从而反向推导私有训练数据。
- **Federated Learning (FL)**：多个客户端协同训练模型而无需共享原始数据，仅交换梯度或参数更新。
- **FET (Fully Expose Text)**：本文提出的离散优化攻击方法，直接在文本空间搜索匹配梯度的序列。
- **Exact Match Rate**：重建文本与原始文本完全一致的比例，衡量精确重建能力。
- **ROUGE Score**：基于 n-gram 重叠和最长公共子序列的文本相似度指标（R-1、R-2、R-L）。
- **Discrete Optimization**：在离散搜索空间（如 token 序列）中寻找最优解的优化方法，区别于连续空间优化。
- **Genetic Algorithm**：模拟自然选择的迭代优化算法，通过选择、交叉、变异操作进化种群。
