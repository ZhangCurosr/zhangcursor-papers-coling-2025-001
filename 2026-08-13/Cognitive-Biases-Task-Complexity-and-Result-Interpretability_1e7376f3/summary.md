# 论文速读：Cognitive-Biases-Task-Complexity-and-Result-Interpretability

## 一句话总结
本文系统评估了大型语言模型在四种认知偏差（首因偏差、近因偏差、常见词偏差、多数类偏差）下的表现，并首次将任务复杂度纳入分析，揭示了模型容量、指令微调与任务难度对认知偏差强度的交互影响，同时指出既往文献中将部分首因/近因效应误判为常见词偏差的问题。

## 研究问题与动机
1. **认知偏差在 LLM 中的量化不足**：已有研究（如 Zhao et al., 2021; Dubey et al., 2024）证实了 LLM 存在认知偏差，但未系统考察不同偏差类型之间的相互作用及干扰问题。
2. **任务复杂度被忽视**：Shrawgi et al. (2024) 发现社会偏差在任务复杂度升高时更显著，但认知偏差领域尚未有人系统操控任务难度并测量其对偏差强度的影响。
3. **Base 与 Instructed 模型行为差异未充分比较**：多数工作将 base 和指令微调模型混为一谈，而监督指令微调可能显著改变模型的偏差表现（Alzahrani et al., 2024; Gupta et al., 2024）。
4. **评估方法的可靠性存疑**：常见词偏差（common token bias）的评估受到位置偏差的严重干扰，导致既往研究结论可能存在误判。

## 核心贡献（创新点）
1. **首次系统地将任务复杂度操控引入认知偏差评估**：通过增减选项数量（ARC 3/4 选项、SST-2 引入中性类）操纵任务难度，揭示复杂度对不同类型偏差的非均匀影响——多数类偏差随复杂度增大，而近因偏差反而减弱。
2. **揭示了不同认知偏差间的相互干扰机制**：证明在 DBPedia 任务中，既往被归因为常见词偏差的结果实际上强烈受到首因和近因偏差的混淆影响，随机打乱标签顺序后该效应消失。
3. **全面比较了 Base vs Instructed 模型在多种偏差下的鲁棒性**：发现增大模型容量（参数量↑ 或 指令微调）整体降低偏差效应量，但指令微调的效果依赖具体模型和偏差类型（如 BLOOMZ 的多数类偏差反而更强）。
4. **纠正了 Zhao et al. (2021) 对常见词偏差的归因**：通过多组对照实验表明，Zhao et al. 观察到的"偏好高频词"现象部分实为首因偏差的遗留效应。

## 方法详解
- **模型选择**：FLOR-BLOOM 模型族（1.3B/6.3B base + 对应 instructed）和 Mistral-7B（base + instructed），利用 FLOR 的持续预训练语言适应特性与 BLOOM 形成对照。
- **评估框架**：使用 EleutherAI Evaluation Harness v0.4.2 计算每个选项的对数概率，取最大概率选项作为预测；统计检验使用 SciPy 实现 $\chi^2$ 拟合优度检验和独立性检验，效应量用 $\varphi$ 系数和 Cramér's V 系数报告。
- **首因/近因偏差实验**：在 ARC（Easy/Challenge）零样本多选题上，对每道题生成 4 个实例（正确答案分别置于 A/B/C/D 四个位置），评估首因时排除 D 位置（只分析 A/B/C），评估近因时排除 A 位置（只分析 B/C/D），以避免两偏差相互污染。
- **任务复杂度操控**：对 ARC 随机删除一个错误选项得到 3-选项简单版（每个实例提示 3 次轮换正确位置）；对 SST-2 在 4-shot 示例间插入中性类得到 5-shot 困难版。
- **多数类偏差实验**：在 SST-2 上使用所有非平衡 4-shot 分布（正/负类数量不等），测量预测标签与 few-shot 中多数类的关联性。
- **常见词偏差实验**：在 DBPedia（保留 8 个单 token 标签的 40k 实例子集）上比较三种 prompt 设置：原始标签顺序、随机打乱标签顺序、不列出标签；同时结合 Google Ngrams 频率和 BPE tokenizer 索引双重验证 token 频次。

## 实验与结果
- **数据集**：ARC-Easy/Challenge（科学推理多选）、SST-2（情感分类）、DBPedia（14 类主题分类，后缩减为 8 类单 token 标签）。

- **首因偏差**（Table 2）：所有模型均呈现显著首因效应，效应量范围为 0.04–1.16；小模型（FLOR-1.3B base: 0.71–0.73）远大于大模型（Mistral-Instructed: 0.04–0.08）；4 选项版效应量普遍大于 3 选项简单版。

## 相关工作脉络
1. **Zhao et al. (2021) Calibrate before use**：在 GPT-2/GPT-3 上首次系统评估四种认知偏差，本文复现其 DBPedia 实验但得出不同结论——部分"常见词偏差"实为位置偏差的混淆结果。
2. **Dubey et al. (2024) Llama 3 鲁棒性分析**：考察 prompt 顺序对 Llama 模型的影响，发现大模型更鲁棒；本文在其基础上进一步区分了偏差类型并引入任务复杂度变量。
3. **Shrawgi et al. (2024) 社会偏差与任务复杂度**：首次提出社会偏差随任务复杂度升高而增强，本文将此框架迁移至认知偏差领域，发现不同偏差对复杂度响应不同。
4. **Wang et al. (2023) ChatGPT 首因效应**：仅关注零样本标签顺序影响，未涉及任务复杂度或多偏差交互；本文提供了更全面的多模型、多偏差、多复杂度对照。
5. **Malaviya et al. (2022) 标注启发式偏差**：指出数据集标注过程中的首因/近因 artifacts 会传导至模型；本文从模型侧验证了这一假设，并区分了数据 artifact 与生成过程 artifact 的贡献。
6. **Itzhak et al. (2024) Instructed to bias**：发现指令微调模型出现新兴认知偏差；本文部分印证此结论（如 BLOOMZ 多数类偏差增强），但也发现指令微调在多数情况下降低偏差。

## 局限性与未来方向
- **分析范围有限**：仅使用 FLOR-BLOOM 和 Mistral 三个模型族及三个数据集，结论的泛化性有待更多模型和任务验证（论文自述）。
- **常见词偏差未能完全分离**：受限于训练数据访问权限和计算预算，无法精确量化每个标签在预训练数据中的实际频次，无法彻底排除或确认常见词偏差的独立存在（论文自述）。
- **任务复杂度操控单一**：仅通过增减选项数量操纵复杂度，未探索其他维度（如输入多样性、关系复杂度等）。
- **未来方向**：开发更精确的常见词偏差检测方法；扩展到更多数据集和模型族；探索偏差干扰下的公平评估协议。

## 研究启发与可借鉴点
1. **偏差隔离的实验设计**：通过排除干扰位置（评估首因时排除末位、评估近因时排除首位）来隔离单一偏差效应，这一策略可直接迁移至其他位置敏感任务的评估中。
2. **任务复杂度作为偏差调节因子**：将 Liu & Li (2012) 的任务复杂度框架操作化为"选项数量"的增减，为后续研究提供了可复用的复杂度操控范式。
3. **多重偏差交互意识的建立**：本文证明了在 DBPedia 任务中常见词偏差与位置偏差的混淆，提醒后续研究在评估任何单一偏差时必须先排除其他偏差的污染，建议将"偏差净化"纳入标准评估流程。
4. **Base vs Instructed 的差异化分析**：指令微调并非一概增强或减弱鲁棒性，不同模型和不同偏差类型响应不同；后续研究应避免对指令微调效果做笼统推断，需分偏差类型精细分析。
5. **多源频次验证策略**：结合 Google Ngrams（网络语料）和 BPE tokenizer 索引（预训练数据代理）双重验证 token 频次，为多语言模型下的词频分析提供了可行方案。

## 关键术语表
- **首因偏差（Primacy Bias）**：模型倾向于赋予列表中首个选项更高权重并更易选择它的系统性倾向。
- **近因偏差（Recency Bias）**：模型倾向于赋予列表中末尾选项更高权重的系统性倾向（注意：本文使用的定义是位置意义上的"末位"，而非时间意义上的"最近"）。
- **多数类偏差（Majority Class Bias）**：在 few-shot 场景中，模型倾向于预测示例中占多数的类别，类比心理学中的可得性启发式。
- **常见词偏差（Common Token Bias）**：模型更倾向于选择预训练数据中频次更高的 token 作为答案，是词频效应在 LLM 中的体现。
- **任务复杂度（Task Complexity）**：由任务的内在特征（如选项数量、输入多样性等）决定的决策难度，本文采用选项数量作为操纵变量。
- **Cramér's V 系数**：基于 $\chi^2$ 统计量的关联性效应量指标，取值 0–1，用于衡量分类变量间的关联强度。
- **$\varphi$ 系数**：2×2 列联表的 $\chi^2$ 效应量指标，本文用于衡量二元位置偏差的强度。
- **Evaluation Harness**：EleutherAI 开发的 LLM 评估框架，通过计算预定义候选选项的概率分布来消除格式变异，保证评估一致性。
