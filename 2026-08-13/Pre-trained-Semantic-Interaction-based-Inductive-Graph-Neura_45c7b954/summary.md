# 论文速读：Pre-trained-Semantic-Interaction-based-Inductive-Graph-Neura

## 一句话总结
本文提出了 **PaSIG**，一种基于预训练语义交互的归纳式图神经网络，通过构建文本-词语异构图的**不对称拓扑结构**实现训练/测试节点严格隔离，结合**门控融合机制（GFUS）**与**子图采样策略**，在五个文本分类基准上平均提升 2.7% 准确率并达到 SOTA。

## 研究问题与动机
1. **集合推理式（Transductive）方法的信息泄漏**：现有 GNN 文本分类方法常构建语料级全图，训练时即可通过消息聚合“看见”测试节点特征，违背归纳学习原则。
2. **图结构僵化与扩展性差**：一旦建图完成便无法修改，新增测试文本必须重建图并重训，难以适应流式或动态数据场景。
3. **归纳式方法缺乏显式跨文本交互**：现有 Inductive 模型多为单篇文档独立建图，虽避免了泄漏，但丢失了语料级文本间的语义交互信号，表征能力受限。
4. **PLM 与 GNN 的割裂**：预训练语言模型（如 BERT）虽能提取富含类别的语义，但其文本交互是隐式的；如何将 PLM 的强表征能力与 GNN 的显式图交互高效结合，仍缺乏通用解决方案。

## 核心贡献（创新点）
1. **提出归纳式文本学习框架 PaSIG**：通过不对称邻接矩阵强制词节点向文本节点单向传递消息，从根本上切断测试集对训练过程的影响。
2. **设计异构感知门控融合机制（GFUS）**：在消息聚合后引入节点类型偏置与可学习门控信号，使模型能自适应权衡节点自身类别特征与邻居异质信息的融合比例。
3. **提出低成本的子图传播策略（PaSIG-S）**：通过采样一阶词邻居与二阶文本邻居构建局部子图，结合中间状态保存技术，实现无需重训的快速推理。
4. **系统验证与 SOTA 性能**：在 MR、Ohsumed、20NG、R8、R52 五个数据集上全面超越归纳式与集合推理式基线，平均准确率提升 2.7%。

## 方法详解
- **图结构构建**：构建包含 `n` 个词节点、`m` 个训练文本节点、`p` 个测试文本节点的异构图。邻接矩阵初始分块为词-词（PMI 权重）、词-文（TF-IDF 权重）和文-文（相似性）三部分。为支持归纳学习，**令测试文本到词的反向边矩阵 P 为零矩阵**，并移除密集的 W-W 边（PMI）以避免内存溢出与噪声干扰，最终得到仅允许词→文本单向传息的**不对称图**。每个节点添加自环。
- **PLM 微调与节点编码**：仅在训练集上微调 BERT，使其输出富含分类语义的嵌入。词节点输入 `[CLS] w [SEP]` 取词 token 输出作为特征；文本节点取 `[CLS]` 输出。测试文本使用相同的微调后 BERT 独立编码，不与训练数据共享计算图。
- **GFUS 聚合机制**：沿用 Message Passing 范式。对节点 `v`，先聚合邻居消息 `m_v^{l+1} = Σ Ŝ_{v,u} h_u^l`，再计算门控信号：
  `λ^l = δ( h_v^l W_h^l + m_v^{l+1} W_m^l + β^l t_v )`，其中 `t_v` 为节点类型（0/1），`β^l` 为可学习类型偏置，`δ` 为 Sigmoid。融合表示为 `ḣ_v^l = λ^l h_v^l + (1-λ^l) m_v^{l+1}`，经线性层与非线性激活得到下一层隐状态。最后一层输出类别概率，损失为训练文本的交叉熵。
- **训练/推理分离与加速**：训练时输入 `(A_train, X_train)`，推理时输入 `(A_test, X_test)`，因无反向边，测试节点仅被动接收消息而不影响参数更新。提出 **PaSIG-S**：对每个文本采样 `k1` 个一阶词邻居、`k2` 个二阶文本邻居构建独立子图训练。基于 In-Degree 归一化下词节点第一层输出在训练/测试阶段保持一致的代数性质，**保存第一层隐藏状态与第二层权重**，新文本推理时仅需单层传播即可预测，大幅降低延迟。

## 实验与结果
- **数据集**：MR（短文本情感，2类）、Ohsumed（医学文献，23类）、20NG（长文本新闻，20类）、R8/R52（Reuters新闻，8/52类）。
- **基线**：归纳式（TextING, HyperGAT, TextSSL, TextFCG, MHGAT）与集合推理式（TextGCN, TextSGC, TensorGCN, HeteGCN, BertGCN）。
- **主要结果**：PaSIG 在全部 5 个数据集上均以 `p < 0.05` 显著超越所有基线。**平均准确率提升约 2.7%**。Ohsumed 提升最显著（+7.67% Acc / +6.43% F1），MR 提升 2.13%，R52 的 F1 提升达 9.25%。PaSIG-S 配合采样策略在多数数据集上与全图版本持平或更优。
- **消融结论**：去除 BERT 嵌入（换 GloVe）、去除微调（直接使用预训练 BERT）、去除图结构（仅用 Fine-tuned BERT）均导致性能大幅下降，证明“类别语义注入”与“图交互”缺一不可。将 BERT 嵌入直接套用在其他归纳基线上反而无效，凸显 PaSIG 架构对 PLM 的专用适配性。
- **组件分析**：GFUS 在子图场景下全面优于 GCN/GIN/SAGE；GCN/GIN 强烈偏好 Out-Degree 归一化，而 GFUS 因门控自适应机制对 Degree 矩阵选择不敏感。
