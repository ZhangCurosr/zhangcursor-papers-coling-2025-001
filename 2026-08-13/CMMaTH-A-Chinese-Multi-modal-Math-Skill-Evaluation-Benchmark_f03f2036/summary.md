# 论文速读：CMMaTH: A Chinese Multi-modal Math Skill Evaluation Benchmark for Foundation Models

## 一句话总结
本文提出了面向中国K12教育场景的多模态数学能力评测基准**CMMaTH**（共23,856道题目、784个细粒度知识点）与配套的开源轻量级答案比对工具**GradeGPT**，系统揭示了当前主流开源与闭源多模态大模型在中文多模态数学推理上的显著能力差距。

## 研究问题与动机
1. **中文多模态数学评测空白**：现有主流基准（如MathVista、CMMMU、MATH-Vision）多以英文为主、题目多样性不足或缺乏贴合中国真实K12试卷的视觉与题型分布，难以有效评估中文语境下的多模态数学能力。
2. **知识点粒度缺失**：既有基准普遍缺乏与教学大纲对齐的细粒度知识标注，无法精准诊断模型在特定数学技能（如立体几何、流程图解读）上的掌握程度。
3. **评测成本与稳定性瓶颈**：当前多模态数学题答案校验高度依赖GPT-4等商业API，成本高、延迟大且结果不稳定；而纯规则抽取难以适配开放问答、多选择题等复杂输出格式。
4. **动态更新困难**：基于硬编码规则或昂贵API的评测流程难以支撑基准的持续迭代与规模化维护。

## 核心贡献（创新点）
1. **构建CMMaTH基准**：收集并清洗来自“教研云”与“组卷网”的23,856道真实中文K12多模态数学题，覆盖14类视觉主题与784个细粒度知识点，是目前规模最大的中文多模态数学评测基准；与已有工作相比，本文聚焦真实试卷分布而非合成/竞赛场景，且提供完整的知识图谱对齐标注。
2. **提出GradeGPT评测工具**：基于Qwen-14B微调开源答案比对模型，引入**CL-JoC（跨语言判断链）**指令格式，实现稳定、零成本、可动态维护的评分；与PandaLM/CritiqueLLM等通用文本评测器不同，GradeGPT专为多模态数学结果一致性判别设计。
3. **建立细粒度能力诊断体系**：提出**KSSR（Knowledge Successful Solve Rate）**指标刻画模型对知识点的全局掌握曲线，并结合人工错误分类（感知/推理/计算/拒绝）与跨语言推理实验（En-CoT、CLP），系统剖析当前模型的瓶颈。

## 方法详解
1. **数据构建流程**：
   - **来源**：“教研云”（版权购买，含5531个知识点标签）与“组卷网”（约40万题目）。
   - **过滤**：剔除纯文本题、非中题目、图像尺寸<100像素的低质题；使用GPT-4进行置信度打分（1-5），低于3分的样本剔除，并辅以人工抽检（500题×3次）。
   - **标注**：借鉴教研云知识图谱映射至784个核心知识点；组卷网数据先由GPT-4生成参考答案与知识点分类，再经人工复核。
2. **GradeGPT设计**：
   - **基座**：Qwen-14B-Chat。
   - **指令构造（CL-JoC）**：模型输出中文 → 提取含答案的关键句并翻译为英文 → 识别标准答案类型 → 判断是否包含/等价于参考答案 → 输出`<Yes>`或`<No>`。
   - **训练数据**：利用多个开源/闭源模型在CMMaTH上的生成结果，经GPT-4 Few-shot生成约5.6万条跨语言判断指令对。
   - **训练配置**：8×H800，batch size=16，lr=1e-4，gradient accumulation=16，训练10个epoch。
3. **KSSR指标**：$KSSR@α = \frac{\sum_{i=1}^{N_{kn}} I(Acc_{kn_i} > α)}{N_{kn}}$，用于度量模型在知识点上准确率超过阈值α的比例，反映技能掌握深度。

## 实验与结果
- **数据集规模**：共23,856题（单选13,706、多选/组合4,485、开放5,665），覆盖小学1-12年级，平均长度75词，最大593词。
- **评测基线**：15个开源模型（LLaVA系列、InternVL2、Qwen2-VL、Yi-VL、CogAgent等）+ 4个闭源API（GPT-4V/o、Gemini-Pro、Claude-3.5），以及随机/高频猜测与人类基线。
- **主要结果**：
  - 闭源模型最强：**GPT-4o 47.8%**，其次Claude-3.5（37.4%）与Gemini-Pro（37.4%）。
  - 开源模型最强：**InternVL2-8B 23.9%**，OpenGVLab系列整体落后闭源模型约15-20个百分点。
  - 人类基线平均约**51.6%**，当前SOTA仍未达到人类水平。
  - 视觉题型分化明显：条形图（Bar）与抽象类比题（Abt-Analogy）得分最高，雷达图（LiDAR）与立体几何（Solid）为薄弱环节。
- **辅助信息实验**：添加OCR Caption后部分模型提升有限，去除视觉输入后商业模型准确率断崖式下跌（如GPT-4o从47.8%降至17.9%），验证题目对视觉内容的高度依赖。
- **跨语言推理**：无训练条件下，En-CoT与CLP对中文多模态题提升幅度有限（最高+13.7%），表明模型在跨语言OCR与语义对齐上仍存在瓶颈。
- **GradeGPT有效性**：在0.5k开发集上达到**96.1%**的判断准确率，显著优于朴素微调（51.5%）与4-shot Qwen-7B（85.1%），逼近GPT-4 Few-shot（97.2%）。

## 相关工作脉络
1. **MathVista / MATH-Vision / MathVerse**：英文为主的多模态数学基准，侧重合成数据或竞赛难度；本文聚焦真实中国K12试卷分布，并提供细粒度知识标注。
2. **CMMMU / C-Eval**：中文综合评测基准，但数学子集仅540题且缺乏知识点与视觉题型细分；本文在规模、题型多样性与教育对齐上显著领先。
3. **MathBench**：首个引入细粒度知识点的中文数学基准，但仅限纯文本；本文将其扩展至多模态场景并同步提供评测工具。
4. **PandaLM / CritiqueLLM**：基于开源LLM蒸馏GPT能力的通用文本评测器；本文针对多模态数学答案一致性设计CL-JoC，专注结果比对而非文本质量维度。
5. **GeoEval / OlympiadBench**：几何专项或竞赛级双语基准；本文覆盖更广泛的K12日常题型（流程图、统计图表、折叠图等），教育适用性更强。

## 局限性与未来方向
1. **过程评估缺失**：GradeGPT仅为结果导向的粗粒度比对器，无法追踪多步推理过程中的逻辑偏差；构建细粒度过程评测模型是明确未来方向。
2. **跨语言推理瓶颈**：无训练时En-CoT/CLP提升有限，暗示当前多模态模型在中文视觉文本识别与跨语言推理协同上仍需强化。
3. **题型覆盖边界**：数据集虽覆盖14类视觉主题，但未包含高等数学、编程数学或极端复杂排版题型，泛化至高等教育场景存在局限。
4. **动态维护成本**：尽管工具支持动态更新，但高质量知识图谱标注仍依赖人工复核，规模化扩展需进一步自动化。

## 研究启发与可借鉴点
1. **CL-JoC跨语言判断链可迁移至多语种评测**：将本地语言关键输出翻译为英文再与标准答案比对，有效缓解开源多语言模型在指令遵循与数值对齐上的不稳定性，可复用于物理、化学等多学科评测。
2. **KSSR曲线诊断范式**：通过知识点对应准确率阈值聚合，生成模型能力剖面图，为后续模型迭代提供可操作的短板定位，适用于任意带细粒度标签的垂直领域基准。
3. **商业知识图谱+人工复核的数据构建流水线**：直接复用成熟的学科知识图谱（如教研云），结合GPT辅助初标+双人交叉校验，可在较低人力成本下快速构建高质量领域基准。
4. **开源评测器蒸馏替代API的可持续实践**：以14B开源模型+5.6万高质量指令对微调，达到接近GPT-4 Few-shot的判定精度，为社区提供低成本、可私有化部署的评测基础设施。

## 关键术语表
**CMMaTH**：Chinese Multi-modal Math Skill Evaluation Benchmark，面向中国K12教育的多模态数学能力评测基准。
**GradeGPT**：基于Qwen-14B微调的开源答案比对模型，支持稳定、零成本的多模态数学结果评估。
**CL-JoC（Cross-Lingual Judge-of-Chain）**：跨语言判断链提示格式，通过将中文模型输出关键句翻译为英文再与标准答案比对，提升结果一致性判定的准确性。
**KSSR（Knowledge Successful Solve Rate）**：知识成功解决率，衡量模型在特定知识点上求解正确率超过阈值α的知识点占比。
**Composition Question**：组合题，数据集特有的多步综合题型，通常融合多个子问题或跨知识点考查。
**Visual Subject**：视觉主题，指题目中依赖图像理解的内容类型（如流程图、三视图、韦恩图、解析几何图等）。
**Perceptual/Reasoning/Calculation/Reject Errors**：四类人工标注的错误类型，分别对应视觉感知错误、逻辑推理错误、数值计算错误与指令拒答/无法作答。
