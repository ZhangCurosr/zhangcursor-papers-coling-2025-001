# 论文速读：Language-Models-Encode-the-Value-of-Numbers-Linearly

## 一句话总结
本文构建加法合成数据集，利用线性探针从 LLM 各层隐藏状态中提取输入数字与计算结果的数值，证明语言模型以线性方式编码数字，并通过激活补丁（activation patching）和线性向量干预实验验证了编码数字与模型输出的因果关联。

## 研究问题与动机
1. 语言模型在数学问题（尤其是算术）上表现薄弱，但其内部如何编码数字这一基础元素仍不清晰。
2. 已有工作多聚焦于小数字或模运算，大范围内数字的编码机制与使用方式缺乏系统研究。
3. 探针得到的信息仅具有相关性，尚未建立编码数字与最终输出之间的因果联系。
4. 理解数字编码方式有助于设计专用编码系统、误差缓解模块，从而提升模型数学能力。

## 核心贡献（创新点）
1. **构建加法合成数据集并系统探测数字编码**：相比以往仅关注小数字或单一任务的 probing 工作，本文覆盖 2–10 位数字并系统分析不同层的编码模式。
2. **发现数字编码呈线性且集中于中间层**：线性探针与非线性 MLP 探针性能相当，证明编码近线性；中间层（如 LLaMA-2-7B 的第 10 层）编码精度最高，与前后层存在显著差异。
3. **揭示数字编码的层级演化模式**：早期层按数字长度（token 数）粗略编码，中间层精细编码，后期层引入均匀噪声，给出"先粗估后精炼"的编码过程解释。
4. **通过干预实验建立数字编码与输出的因果链**：激活补丁显示特定数字 token 的位置选择性影响输出，线性向量加法在中后期层（layer 14–19）实现 73% 的干预成功率，直接证明编码数字被用于计算。

## 方法详解
- **数据集构造**：生成 2–10 位加法问题（$a + b$），共 9000 条，每位数长度 1000 条，按 8:1:1 划分训练/验证/测试集。
- **隐藏状态获取**：在 LLaMA-2-7B/13B、Mistral-7B 上对每个 token 位置保存各层 residual stream $\mathbf{h}_i \in \mathbb{R}^{d_{model}}$。
- **线性探针训练**：使用 Ridge 回归预测 $\log_2(x)$，目标函数为：
  $$\mathbf{W}^*, b^* = \arg\min_{\mathbf{W}, b} ||\log_2(\mathbf{X}) - \mathbf{H}\mathbf{W} - b||_2^2 + \lambda||\mathbf{W}||_2^2$$
  正则化系数 $\lambda = 0.1$；对数值做对数变换以保障数值稳定性。
- **评估指标**：Pearson 系数 $\rho$、出样本 $R^2$、近似准确率 AAcc（误差 < 1%）、MSE。
- **激活补丁（Activation Patching）**：将输入 $a$ 替换为 $a' = 9999$，记录干净与扰动运行下的隐藏状态 $\mathbf{h}'$，在指定层 $i$、位置 $t$ 处替换 $\mathbf{h}_i$，以比值 $E(i,t) = |o^* - o| / |o' - o|$ 衡量影响程度。
- **线性干预（Linear Intervention）**：沿探针权重方向 $\mathbf{d}_i = \mathbf{W}_i / ||\mathbf{W}_i||$ 向 residual stream 添加向量：$\mathbf{h}_i' = \mathbf{h}_i + \alpha \mathbf{d}_i$（$\alpha = 2$），统计成功使输出增大的比例。
- **线arity 检验**：对比两层 MLP 探针（隐藏维度 256，含 ReLU）与线性探针的 MSE，证明非线性未带来显著提升。

## 实验与结果
- **模型基线**：LLaMA-2-7B、LLaMA-2-13B、Mistral-7B（均未微调，贪心解码 max_new_tokens=30）。
- **$\rho$ 与 $R^2$**：所有层均获得较高的 Pearson 系数与 $R^2$，证明数字值存在于隐藏状态；中间层表现最佳，后期层略有下降。
- **AAcc 低于 50%**：线性探针难以精确还原输入数字，MSE 趋势与 $\rho/R^2$ 一致。
- **MLP vs 线性探针**：非线性的 MLP 探针未明显优于线性探针，支持线性编码假设。
- **数字持久性**：编码值在后续 token 位置持续可提取，呈现矩形 MSE 模式；最后一 token 的 probing 精度较低。
- **激活补丁**：每个数位独立影响结果；非数字 token 的补丁几乎无效果；早期层（<14）处理输入数字，后期层（>20）负责计算结果。
- **线性干预**：在 layer 14–19 连续干预的成功率最高达 **0.73**，远超随机/空基准；负方向干预呈现相似趋势。
- **误差控制潜力**：探针提取的 $a, b$ 相加后 logMSE 与 error margin 远低于直接输出，显示编码值可用于误差缓解。

## 局限性与未来方向
- 探针仅为近似重构，无法精确还原原始数字；直接对探针值进行算术计算会产生偏差。
- 实验仅在开源 LLaMA/Mistral 上进行，闭源模型（如 GPT-4）可能呈现不同行为。
- 后续可探索更接近浮点系统的精确编码形式，或设计专用数字编码器从源头消除误差。
- 如何利用探针值构建误差缓解模块，以及精确旋转而非平移向量来改变编码值，仍需进一步研究。

## 研究启发与可借鉴点
1. **对数变换保障数值稳定性**：直接回归大范围数值易出问题，对数变换是值得复用的技巧。
2. **中间层编码精度最高**：在模型压缩或微调时，可优先保留/优化中间层的数值表征通道。
3. **线性干预结合激活补丁形成完整因果链**：从"存在性"到"功能性"的验证范式可迁移至其他可解释性研究。
4. **近似准确率 AAcc 作为补充指标**：除相关性指标外，引入任务敏感的精确性度量更具解释力。
5. **部分数字序列的增量编码发现**：大数被逐 token 增量编码，精度随长度衰减，提示可据此设计分段的数字处理模块。

## 关键术语表
**Linear Probe（线性探针）**：通过线性回归从神经网络隐藏状态中提取特定语义信息的可解释性工具。
**Activation Patching（激活补丁）**：将模型在某层某位置的激活值替换为另一输入的对应值，以量化该位置对输出的因果影响。
**Residual Stream（残差流）**：Transformer 各层中累积信息的向量表示，是线性干预操作的目标空间。
**Approximate Accuracy（AAcc）**：预测值与真实值相对误差小于 1% 的比例，衡量数值编码的精确程度。
**Pearson Correlation ($\rho$)**：衡量探针预测值与真实值之间线性相关程度的统计量。
**Ridge Regression（岭回归）**：在线性回归基础上加入 L2 正则化的回归方法，用于稳定探针训练。
**Logarithmic Encoding**：对输入数值取以 2 为底的对数后再进行探针训练，以提升大范围数值的数值稳定性。
**Causal Mediation Analysis**：通过干预中间变量来量化其对最终输出的因果贡献的分析框架。
