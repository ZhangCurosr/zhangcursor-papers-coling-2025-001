# 论文速读：PoemBERT: A Dynamic Masking Content and Ratio Based Semantic Language Model For Chinese Poem Generation

## 一句话总结
本文提出了 PoemBERT，一个面向中文古诗领域的 BERT 预训练语言模型，通过融合情感与拼音嵌入、设计基于字符重要性（Character Importance）的掩码策略以及动态掩码率策略，在古诗生成、诗→现代文翻译、情感分类和主题分类四个任务上均达到 SOTA。

## 研究问题与动机
1. **领域预训练模型缺失**：现有 BERT 类模型（如 bert-base-chinese）通用语料上训练，缺乏对中文古诗韵律、意象、典故等诗歌特有语言特征的专项学习。
2. **MLM 随机掩码效率低**：传统 BERT 采用 15% 固定比例的随机掩码，部分情况下会掩盖虚词（functioning words），预测过于简单，造成训练效率不高。
3. **中文古诗"一字多音"问题**：古汉语中存在大量通假字、异读字，同一汉字在不同语境下读音不同，仅靠字符嵌入难以捕捉读音信息，影响韵律建模。
4. **诗歌情感表达微妙**：古诗的情感往往通过隐喻、典故等修辞手法含蓄传递，需要模型具备更细腻的情感感知能力。

## 核心贡献（创新点）
1. **PoemBERT 领域预训练模型**：首次提出面向中文古诗的 BERT 预训练模型，在古诗生成、翻译、情感分类、主题分类四个任务上统一达到 SOTA；区别于通用 BERT 仅在通用语料上预训练，PoemBERT 基于专门收集的中国古诗语料（唐诗、宋词等）进行训练。
2. **情感嵌入与拼音嵌入融合**：将 BERT 情感分类器输出的情感嵌入（Sentiment Embedding）和 CNN 提取的拼音嵌入（Pinyin Embedding）与字符嵌入融合；与仅依赖字符嵌入的模型相比，增强了对情感极性和多音字的建模能力。
3. **字符重要性（Character Importance）掩码策略**：提出基于 PMI 的字符重要性度量，优先对语义关联强的实词进行掩码；区别于 ERNIE（基于命名实体掩码）和 SpanBERT（span 掩码），该方法直接针对单个汉字的信息量进行排序与采样，更适合中文古诗单字密度高的特点。
4. **首次论证动态掩码率的合理性并提出三种衰减策略**：证明训练早期高掩码率有助于鲁棒表征学习、后期低掩码率有助于细粒度语义提取和微调对齐；区别于一贯采用固定 15% 掩码率的多数工作，本文给出了理论解释并实验验证了椭圆衰减（elliptical decay）策略的最优性。

## 方法详解
**整体架构**（双阶段）：
- **阶段一**：在细粒度情感诗歌语料（FSPC）上训练 BERT 情感分类器，提取每个字的情感嵌入向量（d 维）。
- **阶段二**：构建融合嵌入后，以古诗语料对 BERT 进行 MLM 预训练。

**融合嵌入（Fusion Embedding）**：
每个字符的三种嵌入——字符嵌入（d 维）、情感嵌入（d 维）、拼音嵌入（d 维）——拼接为 3d 维向量，经全连接层映射回 d 维，再加上位置嵌入后输入 BERT 主干。

**拼音嵌入（Pinyin Embedding）**：
- 用 pypinyin 包将汉字转换为拼音序列，固定长度 8，不足补"-"；
- 使用窗口为 2 的 CNN 提取局部 phonetic 模式，再做 max-pooling 得到 d 维表示；
- 解决"同形异读"（多音字）问题，帮助模型捕捉押韵信息。

**基于字符重要性的掩码策略（Character Importance-based Masking）**：
- 引入 PMI 衡量字符间共现相关性：$\mathrm{PMI}(x, y) = \log \frac{p(x, y)}{p(x)p(y)}$；
- 字符重要性定义为被掩码字符与其余字符 PMI 之和；
- 实际采样时，随机选出 5 个候选字符，按其字符重要性排序后选取 k 个进行掩码，时间复杂度由 $O(C_n^k)$ 降至 $O(kn)$，同时降低过拟合风险。

**动态掩码率策略（Dynamic Masking Rate）**：
- 初始掩码率设为 $2p$（即 30%），随训练进度逐步衰减至接近 $p$（15%）但不趋近 0；
- 比较三种衰减曲线：线性衰减、余弦衰减、椭圆衰减，其中椭圆衰减效果最佳；
- 公式（以 $p=15\%$ 为例）：
  - 线性：$\mathcal{M}_{\text{linear}}(t) = \left(1 - \frac{t}{T}\right) \cdot 2p$
  - 余弦：$\mathcal{M}_{\text{cosine}}(t) = \left(1 + \cos\left(\frac{\pi}{T}t\right)\right) \cdot p + 0.02$
  - 椭圆：分段函数，前半段为 $2p\sqrt{1-\frac{3t^2}{T^2}}$，后半段为 $2p\left(1-\sqrt{1-\frac{3(T-t)^2}{T^2}}\right)$

## 实验与结果
**预训练数据**：chinese-poetry 数据集，含 5.5 万首唐诗、26 万首宋词、2.1 万首宋词词，覆盖约 1.4 万位唐宋诗人。

**基线模型**：Transformer、BERT-base、QA-MLM、AnchiBERT、SA-Model、ERNIE、mT5、LLaMa、GPT-4、ChatGLM。

**下游任务结果（SOTA 汇总）**：

| 任务 | 指标 | PoemBERT | 最佳基线 | 提升幅度 |
|---|---|---|---|---|
| 古诗生成（1→3）| BLEU-4 | **24.91** | ChatGLM 23.85 | +1.06 |
| 古诗生成（2→2）| BLEU-4 | **33.47** | ChatGLM 32.97 | +0.50 |
| 古诗生成（2→2）| Cosine Sim. | **0.717** | ChatGLM 0.701 | +0.016 |
| 诗→现代文翻译 | BLEU-4 | **22.76** | ChatGLM 22.65 | +0.11 |
| 诗→现代文翻译 | Cosine Sim. | **0.672** | ChatGLM 0.649 | +0.023 |
| 情感分类（增强后）| F1 | **84.24%** | ChatGLM 64.01% | +20.23pp |
| 主题分类 | Accuracy | **86.36%** | ChatGLM 83.95% | +2.41pp |

- 情感分类任务上，数据增强（同义替换、释义、删字）使 F1 从无增强的 65.74% 提升至 84.24%，增幅达 **18.50 个百分点**。
- 消融实验（Table 6）表明：情感嵌入（SE）、拼音嵌入（PE）、字符重要性（CI）和动态掩码率（DMR）四个模块均有正向贡献，全模块组合取得最优。
- 不同掩码策略对比（Table 7）：椭圆衰减 > 余弦衰减 > 线性衰减 > 固定 15%，各任务上椭圆衰减均获最高分。

## 相关工作脉络
1. **BERT / Devlin et al., 2019**：通用 MLM 预训练范式，固定 15% 随机掩码，是 PoemBERT 的骨干架构基础。
2. **SpanBERT / Joshi et al., 2020**：span 级掩码策略，避免仅依赖局部线索，但在知识密集型古诗生成任务上表现不佳，PoemBERT 选择单字粒度的 PMI 掩码而非 span 掩码。
3. **ERNIE / Zhang et al., 2019**：基于命名实体的信息性掩码，依赖实体识别能力；PoemBERT 不依赖外部知识库，直接基于 PMI 计算汉字间关联，更轻量且适配古诗文体。
4. **AnchiBERT / Tian et al., 2021**：面向古代汉语的预训练模型，但未引入情感/拼音嵌入和动态掩码策略，PoemBERT 在其基础上进一步融合了多维度特征与训练策略创新。
5. **ChatGLM / GLM et al., 2024**：通用对话大模型，在古诗生成与翻译任务上与 PoemBERT 直接对比，PoemBERT 以参数规模显著更小的优势实现超越，体现了领域预训练的价值。
6. **FSPC 情感数据集 / Chen et al., 2019**：细粒度情感诗歌语料，五类情感标注（负面、隐含负面、中性、隐含正面、正面），是 PoemBERT 情感嵌入训练和分类任务的核心数据。

## 局限性与未来方向
1. 仅试验了 base 规模的 PoemBERT（12 层、768 hidden size），尚未探索 large 及以上规模的效果。
2. 古诗生成任务仍依赖人工评估（5 位专家），评估成本和主观性仍有局限。
3. 字符重要性计算虽优化至 $O(kn)$，但在大规模语料上逐句计算 PMI 矩阵仍有算力开销。
4. 未来工作可扩展至更大规模模型、更多诗歌体裁（如楚辞、元曲），以及跨语言诗歌生成的探索。

## 研究启发与可借鉴点
1. **"情感嵌入+字符嵌入"融合范式可迁移**：将任务相关的辅助嵌入（如情感、拼音、平水韵部）与基础字符嵌入融合，可作为领域 NLP 模型增强的通用手段，适用于对联生成、词牌填词等中文古典文学任务。
2. **动态掩码率策略的理论解释与实验验证具有普遍参考价值**：训练早期高掩码率→鲁棒表征、后期低掩码率→细粒度语义+微调对齐的思路可推广至其他中文专业领域 MLM 预训练。
3. **基于 PMI 的字符重要性采样兼顾信息量与计算效率**：随机采样 5 个候选再排序的策略在保留信息性掩码优势的同时将复杂度从指数级降至线性，这种"采样+排序"的折中思路可复用于其他需要信息性 token 选择的场景。
4. **小数据集上的数据增强策略有效**：在 FSPC 仅数千样本的情况下，通过同义替换、释义和删字将数据扩展至 9 万，F1 提升近 20pp，对低资源古典文本任务具有直接借鉴意义。
5. **拼音嵌入解决多音字问题**：用 CNN 建模拼音序列（固定长度 8，补"-"）的方式轻量高效，可用于其他涉及中文读音敏感的任务（如古诗格律检测、诗词自动押韵分析）。

## 关键术语表
**PoemBERT**：本文提出的面向中文古诗领域的 BERT 预训练语言模型，融合情感与拼音嵌入，采用字符重要性掩码和动态掩码率策略。

**Character Importance（字符重要性）**：基于 PMI 计算的字符语义关联度度量，用于指导哪些汉字更应被选为掩码目标。

**Dynamic Masking Rate（动态掩码率）**：训练过程中随步数逐步降低的掩码比例策略，早期高掩码率（30%）促进鲁棒表征，后期低掩码率促进细粒度学习。

**FSPC（Fine-grained Sentimental Poetry Corpus）**：细粒度情感诗歌语料，包含 5 类情感标注（负面/隐含负面/中性/隐含正面/正面），用于训练情感分类器和提取情感嵌入。

**Pinyin Embedding（拼音嵌入）**：通过 CNN 对汉字拼音序列（固定长度 8）建模得到的 d 维向量，用于捕捉多音字读音信息和押韵特征。

**Sentiment Embedding（情感嵌入）**：由 BERT 情感分类器的 [CLS] 输出向量构成的 d 维表示，用于增强模型对诗歌情感的感知。

**椭圆衰减（Elliptical Decay）**：三种动态掩码率衰减策略中效果最优的一种，掩码率按椭圆函数曲线平滑下降，避免末期掩码率过低。

**BLEU-4 / Cosine Similarity**：古诗生成和翻译任务的自动评估指标，分别衡量 n-gram 重叠度和生成序列与参考序列的语义相似度。
